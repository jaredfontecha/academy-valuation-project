# Academy Sports + Outdoors Valuation Project

## Project Overview

This project analyzes Academy Sports + Outdoors (NASDAQ: ASO) from an investment banking and private equity perspective.

The project will use the company’s historical financial statements to build financial forecasts, estimate its value, and evaluate a hypothetical leveraged buyout.

## Planned Analysis

- Company and industry research
- Historical financial statement analysis
- Three-statement financial model
- Comparable-company analysis
- Discounted cash flow valuation
- Leveraged buyout analysis
- Investment recommendation

## Tools

- Microsoft Excel
- Financial statements and SEC filings
- Git and GitHub
